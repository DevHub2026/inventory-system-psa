# API Documentation

This folder documents the live backend API implemented under backend/. All documentation is implementation-backed; the source of truth is the code under backend/app and backend/routes.

API base: /api/v1 (see backend/routes/api.php for top-level registration)

Contents

- authentication.md — authentication endpoints and middleware
- users-and-roles.md — user and role management endpoints and authorization
- dashboard.md — dashboard API endpoints
- inventory.md — inventory module endpoints (listing, count sessions, stock ops, import/export)
- assets.md — asset endpoints (search, scan, CRUD, borrowable, disposal, reissue)
- borrowings.md — borrowing lifecycle, scan, return, request-borrow
- reservations.md — reservation endpoints and approval flows
- qr-scanning.md — QR resolution and scan history endpoints
- extension-requests.md — borrowing extension request endpoints and workflow
- reports.md — implemented reporting endpoints and export behavior
- errors-and-responses.md — global response format and common error shapes

Source-of-truth: backend/routes/api.php and backend/app/Modules/*/Routes/api.php plus the referenced Controllers, Requests and Resources. Each API document includes source references to the code used to verify the contract.

Note: This documentation is generated by auditing the code. It must be updated whenever controllers, requests or routes change.
