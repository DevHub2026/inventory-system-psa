Generate QR Sheets from Assets JSON

This tool accepts an exported JSON file containing an array of asset objects (similar to the frontend Asset type). It will generate printable PNG sheets (2×4 per A4 page) and package them into a ZIP for download.

How to use

  1. Export assets JSON from your server (see instructions below) or use the frontend API to save a JSON file.
  2. On the target PC open this file in the browser (double-click the file).
  3. Choose the JSON file and click "Generate ZIP".
  4. Download the resulting ZIP and extract to inspect PNG sheets.

Export example (server API)

curl -H "Authorization: Bearer YOUR_TOKEN" "http://your-host/api/assets?per_page=9999" -o assets.json
